Apps Script (Code.gs)

doGet — parameters ที่รับได้

Parameterหน้าที่
?date=YYYY-MM-DDดึง booking วันนั้น (ยกเว้นที่ยกเลิก)
?month=YYYY-MMดึง booking เดือนนั้น (ยกเว้นที่ยกเลิก)
?all=1ดึงทุก booking — ใช้สำหรับ search
?cancelled=1&month=YYYY-MMดึงเฉพาะที่ยกเลิก ของเดือนนั้น
Fields ที่ return: _row, date, time, name, phone, count, allergy, hasAllergy, notes, addedBy, addedAt, editedBy, editedAt, cancelled
_row = row index ใน Sheets (1-based) — ใช้สำหรับ edit/cancel/delete

doPost — actions ที่รับได้

actionหน้าที่
"add"sheet.appendRow() — เพิ่ม row ใหม่
"edit"sheet.getRange(rowIdx).setValues() — แก้ข้อมูล
"cancel"เขียน "ยกเลิก" ลง column สถานะ (M) — soft delete
"delete"sheet.deleteRow(rowIdx) — ลบออกถาวร

Helper Functions

Functionหน้าที่
getColMap(headers)map ชื่อ header → index column
formatTime(val)Date object หรือ string → "HH:mm"
formatPhone(val)number → prepend "0", string → ใช้ตรงๆ
formatDateTime(val)Sheets Date → "YYYY-MM-DD HH:MM"

Parameter forwarding logic

if (cancelled)   → ?cancelled=1[&month=...]
else if (all)    → ?all=1
else if (month)  → ?month=YYYY-MM

Search (🔍)

กดปุ่ม 🔍 มุมขวาบน → โหลด ?all=1 อัตโนมัติ | พิมพ์ทันที → real-time จากชื่อ, เบอร์, หมายเหตุ
⚠️ ต้องแยก _allBookings กับ _allSearchBookings ออกจากกัน
ถ้าใช้ตัวเดียวกัน loadBookings() จะทับข้อมูล all ด้วยข้อมูลรายวัน ทำให้ search filter ติดวัน

Cancel vs Delete

actionผลใน Sheetsมองเห็นใน Dashboard
❌ ยกเลิก เขียน "ยกเลิก" ลง column M (สถานะ) ซ่อนจาก normal view, ดูได้ใน tab ❌ ยกเลิก
🗑️ ลบ ลบ row ออกถาวร หายไปเลย ไม่สามารถกู้คืนได้
ทั้งสองปุ่มแสดงเฉพาะตอน login (authed = true) และ booking ยังไม่ผ่าน (!isPast(b)) และยังไม่ถูกยกเลิก (!b.cancelled)

Known Issues / Notes

หัวข้อรายละเอียด
_row race condition _row index ใช้ตอน load — ถ้ามีคนลบ row พร้อมกัน อาจ edit ผิด row (edge case, low risk)
No API auth ใครรู้ Worker URL ก็ POST ได้ (acceptable สำหรับ internal tool)
วันอังคารบล็อก 2 ชั้น onFormSubmit trigger ใน Apps Script + validation ใน dashboard web form
