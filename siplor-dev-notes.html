⚙️ ขั้นตอน Setup ตั้งแต่ต้น (ถ้าต้องทำใหม่)

1. Google Apps Script

1
เปิด Google Sheets → Extensions → Apps Script
2
วางโค้ดจาก Code.gs ทับโค้ดเดิม → Save
3
ครั้งแรก: เลือก function createBookingForm → Run → Allow permissions → รับลิงก์ Form
4
Deploy → New deployment → Web app
Execute as: Me | Who has access: Anyone → คัดลอก URL
5
เมื่อแก้โค้ด: Deploy → Manage deployments → ✏️ → New version → Deploy

2. Cloudflare Worker

1
cloudflare.com → Workers & Pages → Create → Hello World → Deploy
2
หลัง deploy → Edit code → วางโค้ดจาก worker.js → Deploy
3
คัดลอก Worker URL (เช่น siplor.fxrkssr.workers.dev)

3. Dashboard

1
เปิด dashboard.html แก้ API_URL ให้ตรงกับ Worker URL
2
Push ขึ้น GitHub → Vercel deploy อัตโนมัติ
3
เข้าถึงผ่าน siplor.vercel.app/dashboard.html

🔧 ปัญหาที่เจอและวิธีแก้

ปัญหาสาเหตุวิธีแก้
Sheet not found error Apps Script ใช้ชื่อ sheet ผิด เปลี่ยนมาใช้ getSheets()[0] แทน
โหลดข้อมูลไม่สำเร็จ Apps Script ยังไม่ได้ redeploy หลังแก้โค้ด Deploy → Manage → New version
เดือนนี้แสดงว่างเปล่า Cloudflare Worker ยังเป็น version เก่า ไม่รองรับ ?month= Update Worker code → Deploy
ไม่มีเบอร์โทรศัพท์ Column index ผิด หรือ header ไม่ตรง ใช้ header-based mapping ใน Code.gs
404 บน Vercel Vercel serve index.html เป็น default เปิดด้วย /dashboard.html ตรงๆ
